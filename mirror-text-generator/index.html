Mirror Text Generator

A mirror text generator flips your text as if reflected in glass — each letter is replaced with its mirrored Unicode twin, so "hello" renders as mirrored glyphs in reversed order. This tool gives you four mirror styles at once: horizontal mirror flip, upside-down, plain backwards, and your original next to its mirror image.

What is mirror text?

Mirror text is writing in which every character is horizontally flipped, as if seen in a mirror — the effect Leonardo da Vinci famously used in his notebooks. Unlike backwards text, which only reverses letter order, true mirror text replaces each letter with a reflected glyph (b becomes d, q becomes p) so the result looks like a genuine mirror reflection.

How this mirror text generator works

The tool maps every character of your input to a mirrored Unicode lookalike and then reverses the order, which is exactly what a real mirror does. Its character map draws on mirrored forms from across Unicode: Cyrillic letters that happen to mirror Latin ones (И for N, Я for R, ᗡ for D), IPA and phonetic symbols (ɘ, ɒ, ʜ), and specialized mirrored blocks. Mirror (Horizontal Flip) applies this map for the classic reflection. Upside Down uses rotated glyphs instead (ɐ, ǝ, ʇ) for the upside down text look. Backwards is plain order reversal with no shape change. Original + Mirror places your text beside its reflection, separated for easy comparison.

Everything runs as client-side JavaScript, so the mirrored output is genuine copy-pasteable Unicode — it works anywhere text works, from gaming handles to comment sections.

Where mirror writing shows up

Mirror writing has a long cultural history — da Vinci's notebooks, "mirror writing" puzzles, and novelty signage designed to be read in a rear-view mirror (ambulances famously print AMBULANCE mirrored on the hood). Some visitors search for backwards mirror writing: this tool's horizontal-flip style is exactly that effect. Digitally, mirrored text is popular for aesthetic usernames and bios because the unusual glyphs stand out in a list of plain names. Designers also use it for mock reflections in graphics: rather than flipping an image, they paste actual mirrored characters. The Original + Mirror output is handy for before/after comparisons in tutorials about the effect.

Limitations

A few honest notes. True mirror glyphs don't exist for every character: the map covers Latin letters and digits well, but emoji, CJK characters, and Arabic script pass through unmirrored, which can look patchy in mixed text. Some "mirrored" letters are close visual cousins rather than perfect reflections — an unavoidable compromise when working with real Unicode code points. Mirrored text is also rough on accessibility: screen readers announce the substitute characters literally (often as unrelated letters), and search engines index the glyphs, not your original words. Keep it decorative and short.

Frequently Asked Questions

How to mirror text?

Type into the tool above. It replaces each letter with its mirrored Unicode twin (b→d, e→ɘ) and reverses the order, producing a true mirror reflection you can copy and paste anywhere.

What is the difference between mirror text and backwards text?

Backwards text only reverses letter order ("hello"→"olleh"). Mirror text also flips each letter's shape, like a real reflection. Use the reverse text generator for order-only reversal.

Can I copy and paste mirror text into Instagram or Discord?

Yes. The mirrored output is made of real Unicode characters, so it pastes into bios, usernames, and chats on Instagram, Discord, TikTok, and WhatsApp with no font installation.

Why do some letters look like different alphabets?

Unicode has no dedicated "mirrored Latin" block, so the tool borrows lookalikes — Cyrillic И for mirrored N, IPA ɘ for mirrored e. They are the closest visual matches available as real characters.

Does mirror text work with numbers?

Mostly. Digits with natural mirror twins are mapped (2→Ƨ-style forms); symmetric digits like 0 and 8 stay the same. Results vary by digit, so preview before using numbers in a handle.

Is mirror writing the same as what da Vinci used?

The idea is the same — writing that reads correctly in a mirror — but da Vinci hand-drew reversed letterforms, while this tool substitutes mirrored Unicode characters. The visual effect is equivalent for digital use.

Can screen readers read mirrored text?

Not meaningfully — screen readers announce the substitute glyphs as unrelated characters. Keep mirrored text decorative and short, and never use it for information people need.

Why does emoji stay unchanged in mirror mode?

Emoji have no mirrored Unicode equivalents, so they pass through as-is. Mixing emoji with mirrored letters can look inconsistent — for clean results, mirror plain Latin text.

Is my text uploaded anywhere?

No. The mirroring runs entirely in your browser. Your text never leaves your device.
