Generador de texto spoiler

Un generador de texto spoiler envuelve tu mensaje en el marcado spoiler de cada plataforma para que quede oculto hasta que alguien haga clic — ||así|| en Discord y Telegram, >!así!< en Reddit. Este generador de texto oculto produce cinco formatos listos para copiar de una sola entrada.

Lo esencial

  • Genera 5 formatos: spoiler de Discord, spoiler de Reddit, Discord palabra por palabra, spoiler de Telegram y etiqueta HTML.
  • Discord y Telegram usan ||texto||; Reddit usa >!texto!< — sin espacios dentro de los marcadores.
  • WhatsApp no tiene etiqueta spoiler nativa — estos formatos ahí se muestran literalmente.
  • Los spoilers ocultan, no cifran: cualquiera puede revelar el texto con un clic.
  • Nunca pongas contraseñas ni datos personales detrás de una etiqueta spoiler.

¿Qué es el texto spoiler?

El texto spoiler es un mensaje envuelto en el marcado nativo de ocultado de una plataforma para que no se vea hasta que el lector decida revelarlo. Nació en foros y comunidades de fans para hablar de finales de series, películas y videojuegos sin arruinarle la sorpresa a nadie, y hoy es la etiqueta de cortesía estándar en Discord, Reddit y Telegram.

Cómo funciona este generador de texto spoiler

Escribe tu mensaje y la herramienta lo envuelve en la sintaxis spoiler nativa de cada plataforma. Spoiler de Discord produce ||tu texto||, que Discord muestra como una barra negra hasta hacer clic. Spoiler de Reddit produce >!tu texto!<, el formato nativo de texto oculto de Reddit. Discord (palabra por palabra) envuelve cada palabra por separado (||palabra1|| ||palabra2||) para un efecto de revelado escalonado. Spoiler de Telegram usa la misma sintaxis || || que adoptó Telegram. Etiqueta HTML spoiler te da <span class="spoiler">…</span> para tu propio sitio web, que puedes estilizar con CSS (por ejemplo, fondo negro que se despeja al pasar el cursor).

El envoltorio es puro plantillado de texto en tu navegador — la herramienta no envía tu «spoiler» a ningún lado, lo cual es apropiado, porque el punto es mantenerlo secreto hasta que tú decidas compartirlo.

Cómo usar esta herramienta

  1. Escribe el texto que quieres ocultar en el campo de entrada de arriba.
  2. Los cinco formatos spoiler aparecen al instante, cada uno etiquetado con su plataforma.
  3. Copia el formato de la plataforma donde vas a publicar.
  4. Pégalo en tu mensaje — la plataforma lo oculta automáticamente.

Sintaxis spoiler por plataforma

El error más común es usar la sintaxis equivocada en la plataforma equivocada. Discord y Telegram usan doble pleca: escribe ||, tu texto, || — sin espacios entre las plecas y el texto. Reddit usa >! para abrir y !< para cerrar, también sin espacios internos. WhatsApp no tiene etiqueta spoiler nativa (los formatos de esta herramienta no ocultarán texto ahí), y los comentarios de Instagram tampoco admiten marcado spoiler — en esas plataformas la gente lo simula con saltos de línea o etiquetas de «alerta de spoiler». Ante la duda, genera aquí el formato y pruébalo primero en un canal privado.

Limitaciones

Sé realista sobre lo que hacen las etiquetas spoiler: ocultan el texto, no lo cifran. Cualquiera puede hacer clic para revelar, citar el mensaje o ver el marcado crudo — nunca pongas contraseñas, datos personales ni contenido genuinamente sensible tras una etiqueta spoiler. El marcado spoiler tampoco sobrevive a todo contexto: las notificaciones y vistas previas de mensajes en algunas plataformas muestran el texto oculto, y copiar un mensaje con spoiler a otra app suele revelarlo. Por último, abusar de los spoilers en una comunidad molesta a los lectores; resérvalos para spoilers reales, respuestas de trivia y revelaciones sorpresa.

Preguntas frecuentes

¿Cómo creo texto spoiler?

Escribe tu texto en el generador de arriba y copia el formato de tu plataforma: ||texto|| para Discord y Telegram, >!texto!< para Reddit. Pégalo en tu mensaje y la plataforma lo oculta sola.

¿Cuál es la etiqueta spoiler de Discord?

La etiqueta spoiler de Discord son dos plecas a cada lado del texto: ||spoiler aquí||. Discord la muestra como una barra negra que revela el texto al hacer clic.

¿Cómo funcionan los spoilers en Reddit?

Reddit usa >!spoiler aquí!< — mayor-que, exclamación, texto, exclamación, menor-que — sin espacios dentro de los marcadores. El formato Reddit de este generador lo produce por ti.

¿Telegram tiene etiqueta spoiler?

Sí. Telegram admite ||spoiler|| con la misma sintaxis de doble pleca que Discord, mostrando el texto oculto como un difuminado animado hasta tocarlo. Usa el formato Telegram de esta herramienta.

¿Puedo ocultar texto en WhatsApp con una etiqueta spoiler?

No — WhatsApp no tiene marcado spoiler nativo, así que ||texto|| se mostrará literalmente. En WhatsApp lo típico es avisar con etiquetas «SPOILER» y saltos de línea.

¿Qué hace el spoiler de Discord palabra por palabra?

Envuelve cada palabra en su propio par || ||, para que los lectores revelen la oración palabra por palabra en lugar de todo a la vez. Es popular para respuestas de trivia y revelaciones dramáticas.

¿Cómo añado una etiqueta spoiler en mi sitio web?

Usa el formato HTML de esta herramienta: <span class="spoiler">texto oculto</span>. Luego añade CSS como .spoiler{background:#000;color:#000} y .spoiler:hover{color:#fff} para el efecto de revelado.

¿El texto spoiler es seguro o está cifrado?

No. Las etiquetas spoiler solo ocultan el texto visualmente — cualquiera puede hacer clic para revelarlo, y el texto crudo existe en los datos del mensaje. Nunca uses spoilers para contraseñas o datos personales.

¿Por qué no funciona mi etiqueta spoiler?

Las causas habituales: sintaxis equivocada para la plataforma (|| || en Reddit no funciona), espacios dentro de los marcadores, o una plataforma sin soporte spoiler como WhatsApp o Instagram.
