What Is Bubble Text?

Bubble text is text written with enclosed Unicode characters — letters inside circles, squares, or rounded bubbles — like ⓗⓘ or 🅷🅸. Each "bubble letter" is a single dedicated Unicode code point, not a font effect.

Unicode includes several enclosed alphabets originally created for things like circled list markers and squared signage in East Asia. Four of them contain full A–Z sets, and this tool maps your input onto each one. Because every bubble letter is its own character, the text copies, pastes, and renders identically everywhere — no images, no fonts, no tricks.

How to make bubble letters: type below, pick an alphabet, click Copy. That's the whole process — but read the alphabet notes first, because three of the four styles change your text's case.

Tips for the Best Bubble Text

Short names win. Bubble letters are wide — "MAX" in Negative Square (🅼🅰🆇) is punchy; a full sentence is exhausting.

Circled is the safe default. Oldest Unicode block, lowercase support, best compatibility — when in doubt, ⓗⓘ.

Use Negative Square for maximum pop. White-on-black 🅷🅸 reads like signage and stands out in member lists.

Limitations

  • Three of four alphabets force uppercase — there is no lowercase 🅰 or 🄰 in Unicode.
  • Square alphabets have no enclosed digits; numbers stay plain.
  • Enclosed Alphanumeric Supplement characters (🅰 🅐) need a modern emoji/symbol font; old devices show boxes.
  • Screen readers announce each character's Unicode name — keep bubble text short.
  • Accented letters (é, ñ, ü) have no enclosed forms and pass through unchanged.

Frequently Asked Questions

How to make bubble letters?

Type your text into the generator above and copy one of the four bubble alphabets — Circled (ⓗⓘ), Filled Circles (🅗🅘), Square (🄷🄸), or Negative Square (🅷🅸). Each letter becomes a dedicated Unicode character you can paste anywhere.

Where can I get circled letters copy paste?

The Circled Letters style (Ⓐ–Ⓩ, ⓐ–ⓩ) copies from this page with one click and pastes into Discord, Instagram, TikTok, WhatsApp, and most games. It's the most widely supported bubble alphabet in Unicode.

Why did my lowercase text become uppercase?

The Filled Circles, Square, and Negative Square alphabets only exist as capitals in Unicode, so the tool uppercases your input first. For true lowercase bubble letters, use Circled Letters — it's the only alphabet with a lowercase set.

Why do my numbers look normal in square bubble text?

The square Unicode blocks define no enclosed digits, so 0–9 pass through unchanged. Circled digits become ⓪①②… and filled digits become ⓿❶❷… — pick those alphabets if you need bubble numbers.

What's the difference between bubble text and bubble letters?

On this site, the bubble text maker produces raw Unicode bubble alphabets (ⓗⓘ, 🅷🅸) — pure characters. The bubble letters generator creates decorated bubble name styles with frames and effects. Alphabets for nicknames and labels; decorated styles for display names and bios.

Can I use bubble text for nicknames?

Yes — bubble alphabets are popular for gaming nicknames and Discord names. Circled letters work in the most games; always test your exact styled nickname in-game, since some titles filter enclosed characters.

Which bubble alphabet works on old phones?

Circled Letters (Ⓐ). The Enclosed Alphanumerics block is the oldest of the four and supported almost everywhere. The filled and squared styles come from newer supplement blocks that need current fonts.

Are bubble letters real fonts?

No — each bubble letter is a dedicated Unicode character (like ⓐ U+24D0), not a font style. That's why they work without installing anything and look identical on every device with proper font support.
