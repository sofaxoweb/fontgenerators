Corretor de Quebras de Linha — Arrume Quebras

Cole texto de um PDF ou de uma página da web e quase sempre cada linha quebra no lugar errado — frases cortadas no meio do pensamento, parágrafos estilhaçados em fragmentos. Este corretor de quebras de linha grátis repara linhas quebradas de cinco jeitos: juntar linhas quebradas em parágrafos, reduzir tudo a uma linha, adicionar espaçamento de parágrafo, numerar linhas ou tirar linhas vazias. Cole seu texto, escolha um modo e receba parágrafos limpos.

Pontos principais

  • Cinco modos: juntar linhas quebradas, linha única, espaçamento duplo, numerar linhas, remover linhas vazias.
  • "Juntar linhas quebradas" une quebras simples, mas preserva as quebras de parágrafo das linhas em branco — ideal para colagens de PDF.
  • "Linha única" reduz tudo (incluindo parágrafos) a uma linha aparada.
  • "Numerar linhas" numera cada linha, incluindo as em branco.
  • Roda todo no seu navegador; nada é enviado.

O Que É um Corretor de Quebras de Linha?

Um corretor de quebras de linha é uma ferramenta online que repara quebras de linha indesejadas no texto. Ao copiar de PDFs, e-books, páginas da web ou apps de conversa, o texto costuma chegar com uma quebra dura no fim de cada linha visual — dividindo frases e destruindo a estrutura dos parágrafos. Um formatador de parágrafos como este rejunta esses fragmentos, remove linhas em branco extras ou reformata o espaçamento para o texto voltar a ler como parágrafos de verdade.

Como Este Corretor de Quebras de Linha Funciona

Escolha um dos cinco modos; a correção se aplica na caixa de saída na hora (ou clique em "Corrigir Quebras de Linha"):

  • Juntar linhas quebradas (padrão) — quebras simples viram espaços, então as linhas quebradas se rejuntam em frases fluídas. Linhas em branco são preservadas, então as quebras de parágrafo sobrevivem. Este é o modo para copiar e colar de PDF.
  • Linha única — cada quebra de linha vira um espaço e o texto inteiro colapsa em uma linha aparada. A estrutura de parágrafos é descartada.
  • Espaçamento duplo — linhas vazias são descartadas e as restantes são unidas com uma linha em branco entre cada uma, dando parágrafos espaçados por igual.
  • Numerar linhas — cada linha ganha um número ("1. ", "2. ", ...), incluindo as em branco.
  • Remover linhas vazias — linhas só com espaços são apagadas; todo o resto fica exatamente como está.

Copiar Resultado copia o texto corrigido. Limpar esvazia as duas caixas.

Exemplo Prático

Um poema colado com quebras duras:

Roses are red,
violets are blue.

Sugar is sweet,
and so are you.

Juntar linhas quebradas produz:

Roses are red, violets are blue.

Sugar is sweet, and so are you.

Os dois versos se juntaram em frases, enquanto a linha em branco entre as estrofes sobreviveu — a ferramenta só une quebras simples. O modo linha única na mesma entrada dá uma linha só: Roses are red, violets are blue. Sugar is sweet, and so are you.

Como Usar o Corretor de Quebras de Linha

  1. Cole o texto quebrado na caixa de entrada.
  2. Escolha um modo: "Juntar linhas quebradas" para colagens de PDF/web, "Remover linhas vazias" para textos cheios de buracos, "Linha única" para campos de uma linha.
  3. Confira o resultado — a saída atualiza assim que você troca de modo.
  4. Copie o Resultado e cole o texto corrigido no seu documento.

Juntar Linhas Quebradas vs Linha Única: Qual Modo?

Os dois modos mais usados resolvem problemas diferentes:

  • Use "juntar linhas quebradas" quando o texto tem estrutura real de parágrafos que você quer manter — artigos, redações, capítulos de e-book. Ele cura as linhas quebradas, mas respeita as quebras de parágrafo das linhas em branco.
  • Use "linha única" quando a estrutura precisa sumir por completo: colar num campo de formulário de uma linha, numa célula de planilha, no editor de tuíte ou numa caixa de prompt de IA. Tudo vira uma linha aparada.

Um fluxo comum: junte as linhas quebradas primeiro para restaurar os parágrafos e, se precisar de saída em linha única, troque para o modo linha única — trocar de modo reprocessa a partir da sua entrada original a cada vez. Com a estrutura corrigida, confira o tamanho final com o contador de palavras.

Por Que Copiar de PDF Quebra as Linhas

PDFs guardam o texto como glifos posicionados na página, não como parágrafos fluídos. Ao copiar, a área de transferência recebe uma quebra de linha onde quer que a linha visual terminasse — muitas vezes no meio da frase — além de artefatos de hifenização ("docu-\nmento"). O modo de juntar foi feito exatamente para isso: ele une essas quebras de linha visual de volta em espaços. O que ele não corrige sozinho:

  • Palavras hifenizadas divididas entre linhas ("docu- mento") — remova o hífen manualmente ou com localizar e substituir.
  • Cabeçalhos, rodapés e números de página copiados no meio — apague antes ou depois de corrigir.
  • Layouts de duas colunas, que intercalam as colunas linha a linha — esses pedem reordenação manual.

Limitações

  • "Numerar linhas" numera as em branco também — rode "Remover linhas vazias" antes se quiser numeração contínua só das linhas com conteúdo.
  • Hifens de quebra de linha não são rejuntados ("docu-\nmento" mantém o hífen).
  • Sem detecção inteligente de parágrafos: o modo "juntar" confia nas linhas em branco como quebras de parágrafo; se sua fonte não tem nenhuma, use "espaçamento duplo" depois de juntar para reconstruí-las.
  • Espaços dentro das linhas não são tocados exceto no modo linha única; para limpeza de espaçamento use o limpador de texto.

Perguntas Frequentes

Como corrijo quebras de linha quebradas de um PDF?

Cole o texto e use o modo padrão "Juntar linhas quebradas": ele transforma quebras simples em espaços (rejuntando frases quebradas) e preserva as linhas em branco como quebras de parágrafo. Depois apague manualmente cabeçalhos, números de página ou hifens que o PDF trouxe.

Como tiro quebras de linha do texto por completo?

Escolha o modo "Linha única". Cada quebra de linha vira um espaço e o texto inteiro colapsa em uma linha aparada — ideal para campos de formulário de uma linha, células de planilha ou caixas de prompt.

Qual a diferença entre "juntar linhas quebradas" e "linha única"?

"Juntar linhas quebradas" une só quebras simples e mantém a estrutura de parágrafos das linhas em branco. "Linha única" descarta toda a estrutura e reduz tudo a uma linha. Use juntar para artigos e redações; linha única para destinos de uma linha.

Como numero as linhas de um texto?

Selecione o modo "Numerar linhas" — cada linha recebe seu número no início. Note que as linhas em branco também são numeradas; rode "Remover linhas vazias" antes se quiser numerar só as linhas com conteúdo.

Como removo linhas em branco extras?

O modo "Remover linhas vazias" apaga cada linha só com espaços e deixa todas as outras intocadas — o jeito mais rápido de tirar quebras extras sem juntar nada. Para parágrafos espaçados por igual, use "Espaçamento duplo".

Por que texto copiado de PDF tem quebras no meio da frase?

PDFs guardam glifos posicionados em vez de parágrafos fluídos, então copiar insere uma quebra no fim de cada linha visual. O modo de juntar desta ferramenta reverte exatamente esse estrago.

Dá para formatar texto em parágrafos de verdade?

Sim: "Juntar linhas quebradas" restaura o fluxo dos parágrafos a partir das linhas quebradas, e "Espaçamento duplo" reconstrói a separação uniforme entre parágrafos depois de descartar as linhas vazias.

Meu texto é enviado para um servidor?

Não. Os cinco modos rodam em JavaScript no seu navegador. Seu texto nunca sai do seu aparelho.

Ele corrige palavras hifenizadas divididas entre linhas?

Não — "docu-\nmento" mantém o hífen depois de juntar. Remova esses hifens com localizar e substituir (busque "- " nos fins de linha) antes ou depois de corrigir.
