Conversor CamelCase

Um conversor CamelCase reescreve palavras simples em identificadores estilo programador — "hello world" vira helloWorld — e este produz seis formatos de uma vez: PascalCase, camelCase, snake_case, kebab-case, dot.notation e path/notation. Digite ou cole palavras acima e copie o estilo que sua linguagem ou plataforma espera.

Pontos principais

  • Gera 6 estilos de identificadores de uma entrada: PascalCase, lowerCamelCase, snake_case, kebab-case, dot.notation, path/notation.
  • A pontuação é removida antes da conversão; os dígitos ficam grudados na palavra.
  • Use camelCase para variáveis em JavaScript/Java, PascalCase para classes, snake_case para Python, kebab-case para URLs e CSS.
  • Palavras únicas voltam inalteradas em lowerCamelCase e snake_case — é o correto, não um bug.
  • Um conversor de caixa completo para programadores: seis estilos de identificadores de uma entrada, sem cadastro.
  • A conversão roda no seu navegador; nada é enviado.

O que é camel case?

Camel case é uma convenção de nomes em que identificadores de várias palavras são unidos sem espaços e cada palavra nova começa com maiúscula, como userProfileName — as maiúsculas lembram as corcovas de um camelo. Sua irmã com a primeira palavra maiúscula se chama PascalCase (UserProfileName). Ambas são padrão em programação porque a maioria das linguagens proíbe espaços em nomes de variáveis.

Como este conversor CamelCase funciona

Digite palavras simples e a ferramenta divide sua entrada nos espaços em tokens de palavras, removendo pontuação e símbolos primeiro (então "user's data!" vira as palavras "users" e "data"). Depois ela reconstrói os tokens de seis jeitos: capitalizando cada palavra para PascalCase, minúsculas na primeira palavra para lowerCamelCase, e unindo com underlines, hifens, pontos ou barras para os outros quatro. Se você precisa de um gerador camel case, um conversor pascal case ou um conversor snake case e kebab case, esta página cobre todos — os dígitos ficam grudados na palavra, então "level 2" vira level2 em camelCase e level_2 em snake_case.

As seis transformações são operações puras de string executadas no seu navegador pelo motor conversor da página — sem servidor, sem atraso, sem dados saindo do seu aparelho.

Como usar esta ferramenta

  1. Digite ou cole palavras simples no campo de entrada (ex.: "user profile name").
  2. A ferramenta gera na hora os seis estilos de identificadores abaixo.
  3. Copie o estilo que sua linguagem ou plataforma espera.
  4. Note que a pontuação é removida automaticamente — "don't stop" vira dontStop.

CamelCase vs PascalCase: qual você precisa?

Os dois se confundem o tempo todo, então aqui vai a regra prática usada nos principais guias de estilo: lowerCamelCase (primeira palavra minúscula) para variáveis, funções e propriedades — fetchUserData() em JavaScript. PascalCase (cada palavra capitalizada) para classes, tipos e componentes — UserProfile em Java ou um componente React. O estilo Java do Google, o guia JavaScript da Airbnb e a PEP 8 do Python concordam nessa divisão, e este conversor entrega os dois da mesma entrada para você combinar com qualquer código.

Limitações

Bordas honestas: a pontuação é removida em vez de convertida, então "don't" vira "dont" — confira possessivos e contrações em identificadores à mão. Siglas são tratadas como palavras comuns ("API key" → apiKey, ApiKey), enquanto alguns times preferem APIKey; a ferramenta segue a convenção comum de sigla minúscula e não adivinha a regra do seu time. Escritas não latinas passam pelo divisor, mas não capitalizam de forma significativa. E como qualquer ferramenta de caixa, ela não reconstrói fronteiras de palavras de um identificador já unido — userprofilename não volta a se dividir em palavras.

Perguntas Frequentes

Como converter para camelCase?

Digite palavras simples como "user profile" na ferramenta acima. Ela devolve na hora lowerCamelCase (userProfile) mais cinco outros estilos. Copie o que precisar — sem cadastro, sem envio.

Qual a diferença entre camelCase e PascalCase?

camelCase deixa a primeira palavra minúscula (userName) e é usado para variáveis e funções. PascalCase capitaliza cada palavra (UserName) e é usado para classes e tipos. Esta ferramenta gera os dois da mesma entrada.

Qual caixa devo usar em identificadores de programador?

Siga a convenção da sua linguagem: variáveis camelCase em JavaScript/Java, snake_case em Python/Ruby, kebab-case para classes CSS e slugs de URL, PascalCase para nomes de classe em quase todo lugar. A tabela acima mapeia cada linguagem.

O conversor também lida com snake_case e kebab-case?

Sim — cada entrada produz seis saídas: PascalCase, lowerCamelCase, snake_case, kebab-case, dot.notation e path/notation. Você recebe todas de uma vez em vez de converter seis vezes.

O que acontece com pontuação e apóstrofos?

A pontuação é removida antes da conversão porque identificadores não podem contê-la. "don't stop!" vira dontStop / dont_stop. Revise contrações manualmente se a redação exata importar.

Dá para converter uma palavra só?

Sim, mas uma palavra só não tem fronteiras para unir: "user" devolve user, User, user, user, user, user. É o comportamento correto — os estilos de caixa só diferem com duas ou mais palavras.

Como os números são tratados na conversão?

Os dígitos ficam grudados na palavra: "level 2 boss" vira level2Boss, Level2Boss, level_2_boss e assim por diante. Dígitos iniciais são mantidos como estão, embora algumas linguagens proíbam identificadores que começam com número.

Minha entrada é enviada para um servidor?

Não. As seis conversões rodam no seu navegador com JavaScript. Suas palavras nunca saem do seu aparelho.

Dá para converter snake_case de volta para palavras normais?

Não com esta ferramenta — ela converte palavras em identificadores, não o reverso. Dividir um identificador existente de volta em palavras é outro trabalho; para uma limpeza rápida de texto colado, experimente o limpador de texto.
