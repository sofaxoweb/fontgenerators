Gerador de Texto Espelhado

Um gerador de texto espelhado vira seu texto como refletido num vidro — cada letra é trocada por sua gêmea Unicode espelhada, então "hello" vira glifos espelhados em ordem invertida. Esta ferramenta entrega quatro estilos de espelho de uma vez: espelho horizontal, de ponta-cabeça, invertido simples e seu original ao lado da imagem espelhada.

Pontos principais

  • Produz 4 saídas: Espelho (Virada Horizontal), De Ponta-Cabeça, Invertido e Original + Espelho lado a lado.
  • Espelhar muda o formato de cada letra (b→d, e→ɘ), não só a ordem — o efeito de escrita espelhada de Da Vinci.
  • As saídas são caracteres Unicode reais: copiar e colar de texto espelhado funciona em bios, conversas e comentários sem instalar fonte.
  • Para ordem invertida simples sem mudar o formato, use o gerador de texto invertido.
  • Roda todo no seu navegador — nada é enviado.

O que é texto espelhado?

Texto espelhado é a escrita em que cada caractere é virado horizontalmente, como visto num espelho — o efeito que Leonardo da Vinci usou nos seus cadernos. Diferente do texto invertido, que só inverte a ordem das letras, o texto espelhado de verdade troca cada letra por um glifo refletido (b vira d, q vira p), então o resultado parece um reflexo genuíno.

Como este gerador de texto espelhado funciona

A ferramenta mapeia cada caractere da sua entrada para um sósia Unicode espelhado e depois inverte a ordem, que é exatamente o que um espelho de verdade faz. Seu mapa de caracteres busca formas espelhadas pelo Unicode: letras cirílicas que por acaso espelham as latinas (И para N, Я para R, ᗡ para D), símbolos IPA e fonéticos (ɘ, ɒ, ʜ) e blocos espelhados especializados. Espelho (Virada Horizontal) aplica esse mapa para o reflexo clássico. De Ponta-Cabeça usa glifos girados (ɐ, ǝ, ʇ) para o visual de texto virado. Invertido é inversão simples de ordem sem mudar o formato. Original + Espelho põe seu texto ao lado do reflexo, separado para comparar fácil.

Tudo roda como JavaScript no cliente, então a saída espelhada é Unicode genuíno copiável — funciona onde quer que texto funcione, de nicks de jogos a seções de comentários.

Como usar esta ferramenta

  1. Digite ou cole seu texto no campo de entrada acima.
  2. Os quatro estilos de espelho geram na hora abaixo.
  3. Copie seu favorito com o botão de copiar.
  4. Cole em perfis, conversas ou designs — sem fontes especiais.

Onde a escrita espelhada aparece

A escrita espelhada tem uma longa história cultural — os cadernos de Da Vinci, enigmas de "escrita espelhada" e placas de novidade feitas para serem lidas no retrovisor (ambulâncias imprimem AMBULANCE espelhado no capô, como se sabe). Alguns visitantes buscam escrita espelhada invertida: o estilo de virada horizontal desta ferramenta é exatamente esse efeito. No digital, o texto espelhado faz sucesso em nomes de usuário e bios estéticas porque os glifos incomuns se destacam numa lista de nomes comuns. Designers também o usam para reflexos de mentira em artes: em vez de virar uma imagem, colam caracteres espelhados de verdade. A saída Original + Espelho serve para comparações de antes/depois em tutoriais sobre o efeito.

Limitações

Algumas notas honestas. Glifos espelhados de verdade não existem para cada caractere: o mapa cobre bem letras latinas e dígitos, mas emojis, caracteres CJK e escrita árabe passam sem espelhar, o que pode parecer remendado em texto misto. Algumas letras "espelhadas" são primas visuais próximas em vez de reflexos perfeitos — um compromisso inevitável ao trabalhar com pontos de código Unicode reais. Texto espelhado também é duro para acessibilidade: leitores de tela anunciam os caracteres substitutos literalmente (muitas vezes como letras sem relação), e buscadores indexam os glifos, não suas palavras originais. Deixe decorativo e curto.

Perguntas Frequentes

Como espelho um texto?

Digite na ferramenta acima. Ela troca cada letra por sua gêmea Unicode espelhada (b→d, e→ɘ) e inverte a ordem, produzindo um reflexo de espelho de verdade que você copia e cola onde quiser.

Qual a diferença entre texto espelhado e invertido?

Texto invertido só inverte a ordem das letras ("hello"→"olleh"). Texto espelhado também vira o formato de cada letra, como um reflexo real. Use o gerador de texto invertido para inversão só de ordem.

Dá para copiar e colar texto espelhado no Instagram ou Discord?

Sim. A saída espelhada é feita de caracteres Unicode reais, então cola em bios, nomes de usuário e conversas no Instagram, Discord, TikTok e WhatsApp sem instalar fonte.

Por que algumas letras parecem de outros alfabetos?

O Unicode não tem um bloco dedicado de "latim espelhado", então a ferramenta pega sósias emprestados — o cirílico И para o N espelhado, o ɘ do IPA para o e espelhado. São as correspondências visuais mais próximas disponíveis como caracteres reais.

Texto espelhado funciona com números?

Em geral. Dígitos com gêmeos espelhados naturais são mapeados (2→formas estilo Ƨ); dígitos simétricos como 0 e 8 ficam iguais. Os resultados variam por dígito, então confira antes de usar números num nick.

Escrita espelhada é o mesmo que Da Vinci usava?

A ideia é a mesma — escrita que se lê corretamente num espelho — mas Da Vinci desenhava à mão as letras invertidas, enquanto esta ferramenta substitui por caracteres Unicode espelhados. O efeito visual é equivalente no uso digital.

Leitores de tela leem texto espelhado?

Não de forma útil — leitores de tela anunciam os glifos substitutos como caracteres sem relação. Deixe o texto espelhado decorativo e curto, e nunca o use para informação que as pessoas precisam.

Por que o emoji fica inalterado no modo espelho?

Emojis não têm equivalentes Unicode espelhados, então passam como estão. Misturar emojis com letras espelhadas pode parecer inconsistente — para resultados limpos, espelhe texto latino simples.

Meu texto é enviado para algum lugar?

Não. O espelhamento roda inteiramente no seu navegador. Seu texto nunca sai do seu aparelho.
