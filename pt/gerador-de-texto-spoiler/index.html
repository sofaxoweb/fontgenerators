Create hidden spoiler text for Discord, Reddit, and more

Gerador de Texto Spoiler

Um gerador de texto spoiler envolve sua mensagem na marcação de spoiler de cada plataforma, para ela ficar escondida até alguém clicar — ||assim|| no Discord e no Telegram, >!assim!< no Reddit. Este gerador de texto oculto produz cinco formatos prontos para colar de uma vez, para você esconder reviravoltas, respostas de quiz ou anúncios surpresa onde quiser.

Pontos principais

  • Gera 5 formatos: spoiler do Discord, spoiler do Reddit, Discord palavra por palavra, spoiler do Telegram e uma tag spoiler em HTML.
  • Sintaxe do Discord/Telegram: ||texto||. Sintaxe do Reddit: >!texto!<. Não são intercambiáveis.
  • A marcação de spoiler esconde o texto nativamente em cada plataforma — sem bots nem extensões.
  • O texto oculto continua existindo na mensagem: está obscurecido, não criptografado.
  • Roda todo no seu navegador — nada é enviado.

O que é texto spoiler?

Texto spoiler é texto escondido atrás de uma capa clicável — geralmente uma barra preta ou um bloco embaçado — que só revela o conteúdo quando o leitor escolhe descobrir. As plataformas de conversa implementam com marcação simples: pipes duplos (||) no Discord e no Telegram, e >! !< no Reddit. Existe para comunidades discutirem filmes, jogos e livros sem estragar surpresas para os outros.

Como este gerador de texto spoiler funciona

Digite sua mensagem e a ferramenta a envolve na sintaxe nativa de spoiler de cada plataforma. Spoiler do Discord produz ||seu texto||, que o Discord mostra como barra preta até clicar. Spoiler do Reddit produz >!seu texto!<, o formato nativo de texto oculto do Reddit. Discord (Palavra por Palavra) envolve cada palavra separadamente (||palavra1|| ||palavra2||) para um efeito de revelação escalonada. Spoiler do Telegram usa a mesma sintaxe || || que o Telegram adotou. Tag Spoiler em HTML dá <span class="spoiler">…</span> para seu próprio site, que você estiliza com CSS (por exemplo, fundo preto que limpa no hover).

O envolvimento é puro modelo de string no seu navegador — a ferramenta não manda seu "spoiler" para lugar nenhum, o que combina, já que a graça é mantê-lo em segredo até você escolher compartilhar.

Exemplo prático: esconda um spoiler

Entrada: The villain is the butler

Como usar esta ferramenta

  1. Digite o texto que quer esconder no campo de entrada acima.
  2. Os cinco formatos de spoiler aparecem na hora, cada um com o rótulo da plataforma.
  3. Copie o formato da plataforma onde vai postar.
  4. Cole na sua mensagem — a plataforma esconde automaticamente.

Sintaxe de spoiler por plataforma

O erro mais comum é usar a sintaxe errada na plataforma errada. Discord e Telegram usam pipes duplos: digite ||, seu texto, || — sem espaços entre os pipes e o texto. O Reddit usa >! para abrir e !< para fechar, também sem espaços internos. O WhatsApp não tem tag nativa de spoiler (os formatos desta ferramenta não escondem texto lá), e os comentários do Instagram também não suportam marcação de spoiler — nessas plataformas, as pessoas improvisam com quebras de linha ou rótulos de "aviso de spoiler". Na dúvida, gere o formato aqui e teste num canal privado antes.

Limitações

Seja realista sobre o que tags de spoiler fazem: elas obscurecem o texto, não o criptografam. Qualquer um pode clicar para revelar, citar a mensagem ou ver a marcação crua — nunca ponha senhas, dados pessoais ou conteúdo genuinamente sensível atrás de tag de spoiler. A marcação de spoiler também não sobrevive a todo contexto: notificações e prévias de mensagem em algumas plataformas mostram o texto oculto, e copiar uma mensagem com spoiler para outro app costuma revelá-la. Por fim, abusar de spoilers numa comunidade irrita os leitores; reserve para spoilers de verdade, respostas de quiz e revelações surpresa.

Perguntas Frequentes

Como faço texto spoiler?

Digite seu texto no gerador acima e copie o formato da sua plataforma: ||texto|| para Discord e Telegram, >!texto!< para Reddit. Cole na sua mensagem e a plataforma esconde atrás de uma capa clicável.

Qual é a tag de spoiler do Discord?

A tag de spoiler do Discord são dois caracteres pipe de cada lado do texto: ||spoiler aqui||. O Discord mostra como uma barra preta que revela o texto ao clicar. Também funciona para esconder anexos de imagem.

Como funcionam spoilers no Reddit?

O Reddit usa >!spoiler aqui!< — maior-que, exclamação, texto, exclamação, menor-que — sem espaços dentro dos marcadores. O formato Reddit deste gerador produz exatamente essa sintaxe.

O Telegram tem tag de spoiler?

Sim. O Telegram suporta ||spoiler|| com a mesma sintaxe de pipes duplos do Discord, mostrando o texto oculto como um borrão animado até tocar. Use o formato Telegram desta ferramenta para isso.

Dá para esconder texto no WhatsApp com tag de spoiler?

Não — o WhatsApp não tem marcação nativa de spoiler, então ||texto|| aparece literalmente. Usuários de WhatsApp costumam avisar com rótulos "SPOILER" e quebras de linha. Para simulações estilo WhatsApp, veja nosso gerador de conversas falsas de WhatsApp.

O que o spoiler palavra por palavra do Discord faz?

Ele envolve cada palavra no seu próprio par || ||, então os leitores revelam a frase uma palavra por vez em vez de tudo de uma vez. É popular para respostas de quiz e revelações dramáticas em conversas do Discord.

Como adiciono tag de spoiler no meu site?

Use o formato HTML desta ferramenta: <span class="spoiler">texto oculto</span>. Depois adicione CSS como .spoiler{background:#000;color:#000} e .spoiler:hover{color:#fff} para o texto revelar no hover.

Texto spoiler é seguro ou criptografado?

Não. Tags de spoiler só escondem o texto visualmente — qualquer um pode clicar para revelar, e o texto cru existe nos dados da mensagem. Nunca use spoilers para senhas, dados pessoais ou nada realmente sensível.

Por que minha tag de spoiler não funciona?

As causas comuns: sintaxe errada para a plataforma (|| || no Reddit não funciona), espaços dentro dos marcadores, ou plataforma sem suporte a spoiler como WhatsApp ou comentários do Instagram. Copie desta ferramenta o formato exato da sua plataforma.
